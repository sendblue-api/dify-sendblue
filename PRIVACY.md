# Privacy

This plugin sends API requests only to `https://api.sendblue.co`. API key and secret are used in authentication headers. Message sends transmit the recipient, exact text, and optional sending line. Reads retrieve message history, delivery metadata, and sending line state from the connected workspace. Dify receives returned results.

No plugin analytics, extra storage, third-party tracking, or automatic message retries are implemented. Dify stores credentials under its own configuration and security policy. Sendblue processes messaging data under [Sendblue’s privacy policy](https://www.sendblue.com/privacy-policy). Use a workspace containing only data you authorize Dify and your selected model provider to process. Contact support@sendblue.com.
